      Setup

      Game

      Rounds 1 to 3 are single points, rounds 4 and 5 double, round 6 and later triple. Fast Money: player 1 gets 20 seconds, player 2 gets 25.

      Load a new question set

      1. Copy the prompt and paste it into Claude. Replace the bracketed part with your ideas (a theme, inside jokes, who's coming). 2. Copy Claude's whole reply, paste it in the box below, and press Load questions. It replaces both the main game and Fast Money questions and goes back to round 1. Scores stay until you start a new game.

      Main game questions

      One question per block, blank line between blocks. First line is the question, then up to 8 answers, each ending in its points, like Take a nap 35. The survey numbers are made up, so edit freely.

      Fast Money questions

      Same format. The first 5 are for the left team, the next 5 for the right team, so nobody hears their questions ahead of time.

      Host screen

      Open this game's link a second time and add #host to the end. That window shows every answer and the controls; the TV window follows along. Both need to be in the same browser on the same laptop.
